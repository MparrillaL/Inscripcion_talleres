Cómo usar la aplicación

  1. Rellena el formulario y pulsa Inscribirse. Si algún dato no es válido verás el error junto al campo y no se añadirá a nadie.
  2. Usa el buscador y el filtro de modalidad para localizar participantes. Las estadísticas siempre cuentan a todos.
  3. Pulsa Eliminar en una tarjeta y confirma para darla de baja.
  4. En Gestión de datos puedes exportar la lista a JSON o importar otra (solo se acepta si todos los datos son válidos).
  5. En Preferencias elige tema y tamaño de letra; se guardan 30 días en cookies.
